# CLASE-6-

1. Control de Temperatura
   Uso funciones para medir y calcular la temperatura ideal según la ocupación, lo que evita encender equipos innecesariamente, esto mejora el rendimiento al reducir el trabajo del procesador y ahorrar energía eléctrica al mismo tiempo.

2. Gestión de Inventario
   El sistema registra entradas y salidas actualizando los datos directamente en la memoria central del programa sl no crear copias extras de la información, el proceso es mucho más rápido y consume el mínimo de memoria rm.

3. Navegación Autonoma
   Divido la detección de objetos de la acción de frenado para que el auto responda al instante ante peligros, esta estructura permite que el sistema tome decisiones de seguridad sin retrasos, algo fundamental para un tiempo de respuesta rápido.

4. Optimización de Fábrica
   Las funciones vigilan el estado de las máquinas y avisan cuándo dar mantenimiento antes de que algo falle, maximiza la eficiencia porque el código solo actúa cuando es necesario evitando paradas de producción por errores técnicos.

5. Riego Automatizado
   El programa cruza los datos de humedad con el pronóstico del clima externio para decidir si abre o cierra los aspersores, el sistema funciona de forma inteligente y ahorra agua al no procesar tareas de riego si va a llover haciendolo eficiente y ambientalista.
